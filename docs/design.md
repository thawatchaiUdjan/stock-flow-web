# Design direction

The one visual direction every screen follows, so that screens built by different agents, in different sessions, look like one product. Made once, before the first screen: from a Figma file or brand guide when there is one, otherwise drafted with `ui-ux-pro-max` and reviewed with `frontend-design` (`AGENTS.md`, *Design*). Changed only on purpose, in its own pull request.

## Subject

Who uses the product, what it is for, and the one job its screens must do well.

## Color

4–6 named values, each with its role (background, text, accent, state colors).

| Name | Value | Role |
| --- | --- | --- |

## Type

The typefaces and their roles, and the type scale (sizes, weights, line heights).

## Layout

The layout concept, alignment, spacing scale, and the breakpoints down to mobile. ASCII wireframes of the main screen shapes where they help.

## Principles

What makes this product's screens its own: the one place boldness is spent, and what stays quiet around it.

## Voice

How the interface speaks: naming, button labels, errors, empty states.
