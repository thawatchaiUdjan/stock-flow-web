# 0009: UI language: English only

Status: Accepted
Date: 2026-11-05

## What it is for

On-screen copy is English. There is no i18n layer; it is a later feature.

## Why it was chosen

One language needs no message catalogue, and adding one now would be a cost with no user.

## What was not chosen and why

- i18n from the start: every string pays for a feature nobody has asked for yet.
